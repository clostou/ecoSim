# Configuration

The simulation parameters are accessible through the `conf.txt` file.

# CLI arguments

If you run the simulation through a terminal, you can use the following parameters

 - `--headless` Runs the simulation without the GUI
 - `--no_restart` The simulation will exit when over 

# Commands

```
Mouse Wheel: Zoom
Mouse Left : Move view
Mouse Right: Select agent
Space      : Play / Pause
S          : Toggle unlimited framerate
E          : Toggle rendering (for more fps)
G          : Toggle UI
Esc        : Exit
```
